從哪裡開始

按右上角的開新的，有四條路：打一份房間清單、貼上之前的 JSON、 把平面圖照片放到底層描、或載入範例改成你家。

打清單最快。一行一個房間，寫成 客廳 358x487， 先把房間生出來，位置之後用拖的。

排位置

  • 直接拖房間。相鄰時會吸附到兩個位置：留一道牆厚（各自有牆）和完全貼齊（共用一道牆或直接連通）。
  • 要轉向：選起房間後拖上方的圓形把手，任意角度都行，靠近 15 度的倍數會吸附。也可以按工具列的 90 度按鈕，或用中括號做 15 度微調。
  • 兩指捏合可以縮放，空白處拖曳可以平移。

開窗戶和門

  • 選加窗戶或加門，然後點房間的牆線，不是中間。
  • 加好後拖兩端的圓點調寬度，拖中間可以左右移動。
  • 下方欄位可以選種類。沒有門扇的通道選開口（無門），牆會被整段打開。
  • 方位是自動算的。房間轉了幾度，它的窗戶就跟著轉，摘要裡會標成「朝西北西」這種實際方位。

方位怎麼設

左上角選「畫面上方朝哪個方位」。如果你知道大門朝西北，就把大門那面轉到畫面上方， 再選西北——這樣所有窗戶的朝向都會自動算對。討論通風、日照、西曬時就靠這個。

顯示單位

工具列右端可以切換 cm 或 ft/in。畫布標示、輸入欄位、 文字摘要都會跟著換，但 JSON 資料一律以公分儲存，跟別人交換檔案不會亂掉。 呎吋模式下，長度欄位可以輸入 12'6"、76" 或 360cm。

存檔

每次改動都會自動存在你自己的瀏覽器裡，關掉分頁再開回來還在，不會上傳到任何地方。

但瀏覽器的儲存空間可能被清掉（清除瀏覽資料、無痕模式、換裝置）。 重要的圖請到「資料」頁下載一份 JSON 備份。
